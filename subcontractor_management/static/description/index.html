Subcontractor Management

Comprehensive module for managing subcontractor agreements, items, payments, and raw material consumption

Features

  • Subcontractor Agreements: Create and manage agreements with partners
  • Product Variants: Enhanced selector for products with attributes
  • Payment Tracking: Track payments and automatically calculate balances
  • Weekly Payment Wizard: Bulk payment processing for multiple agreements
  • Inventory Updates: Automatic inventory adjustments when agreements are completed
  • Material Consumption: Track raw material usage for subcontractor work

Usage

  1. Install the module
  2. Create subcontractor agreements
  3. Add items with product variants
  4. Record payments
  5. Track material consumption
